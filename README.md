# Para-diversao
 Projeto simples
 😄 Projeto: Clique Surpresa!
Este é um projeto simples e divertido feito com HTML, CSS e JavaScript. A ideia é direta ao ponto: você clica em um botão… e algo inesperado e engraçado acontece! 🎉

💡 Sobre o Projeto
Às vezes tudo que a gente precisa é de um momento de bobeira no meio do caos. Este mini-projeto foi feito com a intenção de provocar um sorriso. Ao clicar no botão, uma "surpresa" aparece na tela — pode ser uma imagem engraçada, uma mensagem aleatória ou até confete explodindo no navegador! Tudo depende da sua criatividade (e do humor do dia 😄).

🛠 Tecnologias Utilizadas
HTML5: estrutura da página.

CSS3: estilos, animações e responsividade.

JavaScript: interação, lógica e a parte "mágica" do botão.
